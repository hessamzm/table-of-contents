# Table of Contents

إضافة خفيفة وقابلة للتوسعة لإنشاء جدول محتويات تلقائي لمحتوى WordPress.

## 1. مقدمة الإضافة

**Table of Contents** هي إضافة خفيفة وقابلة للتوسعة لإنشاء «جدول محتويات» تلقائي في WordPress.

تتعرف الإضافة على عناوين المحتوى داخل المقالات والمنتجات، ثم تنشئ جدول محتويات قابلًا للتخصيص، مع إمكانية التحكم في المظهر والبنية والسلوك بما يناسب الموقع.

أهم الميزات:

- إنشاء جدول محتويات تلقائي من العناوين H1 إلى H6
- إعدادات مستقلة لجدول محتويات مقالات المدونة ومنتجات WooCommerce
- دعم المقالات والصفحات ومنتجات WooCommerce
- اختيار مستويات العناوين المستخدمة في جدول المحتويات
- تخصيص العنوان والنمط والترقيم وطريقة العرض
- دعم Sticky وScroll Spy
- تصميم متجاوب للهواتف والأجهزة اللوحية وأجهزة الكمبيوتر
- دعم Gutenberg Block
- دعم Shortcode لإدراج جدول المحتويات يدويًا
- توافق مع Rank Math ومنع إنشاء جدول محتويات مكرر في السيناريوهات المدعومة
- الحفاظ على معرّفات العناوين الموجودة وإدارة Anchor المكررة
- دعم الترجمة وواجهة المستخدم باللغتين الفارسية والإنجليزية
- توافق مع بنية HPOS في WooCommerce

## 2. المتطلبات

لاستخدام الإصدار 1.0.0، يلزم توفر ما يلي:

- **WordPress:** الإصدار 7.0 أو أحدث
- **PHP:** الإصدار 8.2 أو أحدث
- **WooCommerce:** الإصدار 10.0 أو أحدث، فقط للميزات المتعلقة بمنتجات WooCommerce

لاستخدام ميزات المنتجات، يجب أن يكون WooCommerce مثبتًا ومفعّلًا ومتوافقًا مع الإصدار المطلوب.

## 3. طريقة التثبيت

### التثبيت من لوحة تحكم WordPress

1. قم بتنزيل ملف ZIP الخاص بالإضافة.
2. سجّل الدخول إلى لوحة تحكم WordPress.
3. انتقل إلى **الإضافات > أضف جديدًا**.
4. اختر **رفع إضافة**.
5. حدّد ملف ZIP ثم ثبّته.
6. بعد التثبيت، فعّل إضافة **Table of Contents**.
7. انتقل إلى **الإعدادات > Table of Contents** لفتح صفحة الإعدادات.

### التثبيت اليدوي

1. فك ضغط ملف الإضافة ZIP.
2. ضع مجلد الإضافة داخل المسار:

`wp-content/plugins/table-of-contents/`

3. افتح لوحة تحكم WordPress.
4. انتقل إلى قسم **الإضافات**.
5. فعّل إضافة **Table of Contents**.
6. انتقل إلى **الإعدادات > Table of Contents** لتكوين جدول المحتويات.

## 4. شرح عام وبسيط

بعد تفعيل الإضافة، تصبح إعدادات جدول المحتويات متاحة من خلال صفحة الإعدادات.

### جدول محتويات المقالات

من قسم **Articles** يمكنك تفعيل جدول محتويات خاص بمقالات المدونة، ثم ضبط مستويات العناوين والعنوان والنمط والترقيم والألوان وحجم النص والمسافات وسلوك Sticky.

### جدول محتويات المنتجات

من قسم **Products** يمكنك إعداد جدول محتويات مستقل لمنتجات WooCommerce.

كما يمكنك تحديد موضع جدول المحتويات داخل صفحة المنتج بما يتناسب مع بنية صفحة المنتج.

### استخدام Shortcode

إذا كنت تريد إدراج جدول المحتويات يدويًا في موضع محدد، يمكنك استخدام Shortcode المخصص:

- `[hessamzm_blog_toc]`
- `[hessamzm_product_toc]`

تتضمن صفحة الإعدادات مولّدًا مخصصًا لهذه الأكواد، بحيث يمكنك إنشاء Shortcode ونسخه دون الحاجة إلى حفظ الـ Attributes يدويًا.

تتيح Shortcode إمكانية تخصيص مستويات العناوين والعنوان والنمط والترقيم وSticky والألوان والطباعة والمسافات ونصوص فتح وإغلاق جدول المحتويات.

### منع تكرار جدول المحتويات

لمنع ظهور جدولَي محتويات داخل المحتوى نفسه، تدير الإضافة العلاقة بين جدول المحتويات التلقائي وShortcode.

عند تفعيل جدول المحتويات التلقائي لنوع محتوى معيّن، يتم تعطيل مولّد Shortcode الخاص بالنوع نفسه حتى لا يتم إنشاء جدول محتويات ثانٍ عن طريق الخطأ.

### التعديل والتخصيص

تتم إدارة الإعدادات الأساسية من خلال واجهة WordPress القياسية، ولا تحتاج إلى تعديل ملفات PHP أو CSS للاستخدام المعتاد.

تم تصميم الإضافة لتكون سهلة الاستخدام للمواقع العادية، وفي الوقت نفسه قابلة للتوسعة للمشاريع الاحترافية.

## دعم الترجمة

واجهة الإضافة جاهزة للترجمة وتدعم اللغتين الفارسية والإنجليزية.

## التوافق

تستخدم الإضافة واجهات WordPress القياسية ومصممة للعمل مع إصدارات WordPress الحديثة.

في المواقع التي تستخدم WooCommerce، تم أخذ التوافق مع **High-Performance Order Storage (HPOS)** في الاعتبار.
