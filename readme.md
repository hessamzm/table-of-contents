# Table of Contents

Automatic, extensible Table of Contents for WordPress content.

## 1. معرفی افزونه

**Table of Contents** یک افزونه سبک و قابل توسعه برای ساخت خودکار «فهرست مطالب» در وردپرس است.

افزونه با شناسایی تیترهای محتوای نوشته یا محصول، یک فهرست مطالب قابل تنظیم ایجاد می‌کند و به کاربر اجازه می‌دهد ظاهر، ساختار و رفتار آن را متناسب با سایت خود تنظیم کند.

امکانات اصلی:

- ساخت خودکار فهرست مطالب از تیترهای H1 تا H6
- تنظیم مستقل فهرست مطالب برای نوشته‌های وبلاگ و محصولات ووکامرس
- پشتیبانی از نوشته‌ها، برگه‌ها و محصولات ووکامرس
- انتخاب سطح تیترهای مورد استفاده در فهرست مطالب
- امکان تعیین عنوان، استایل، شماره‌گذاری و نحوه نمایش
- پشتیبانی از حالت Sticky و Scroll Spy
- طراحی Responsive برای موبایل، تبلت و دسکتاپ
- پشتیبانی از Gutenberg Block
- پشتیبانی از Shortcode برای درج دستی فهرست مطالب
- سازگاری با Rank Math و جلوگیری از ایجاد TOC تکراری در سناریوهای پشتیبانی‌شده
- حفظ IDهای موجود تیترها و مدیریت Anchorهای تکراری
- پشتیبانی از ترجمه و رابط کاربری فارسی و انگلیسی
- سازگار با ساختار HPOS در WooCommerce

## 2. پیش‌نیازها

برای استفاده از نسخه 1.0.0 موارد زیر مورد نیاز است:

- **WordPress:** نسخه 7.0 یا بالاتر
- **PHP:** نسخه 8.2 یا بالاتر
- **WooCommerce:** نسخه 10.0 یا بالاتر، فقط برای امکانات مربوط به محصولات ووکامرس

برای استفاده از قابلیت‌های محصولات، WooCommerce باید روی سایت فعال و دارای نسخه سازگار باشد.

## 3. آموزش نصب

### نصب از طریق پیشخوان وردپرس

1. فایل ZIP افزونه را دریافت کنید.
2. وارد پیشخوان وردپرس شوید.
3. به مسیر **افزونه‌ها > افزودن افزونه** بروید.
4. گزینه **بارگذاری افزونه** را انتخاب کنید.
5. فایل ZIP افزونه را انتخاب و نصب کنید.
6. پس از نصب، افزونه **Table of Contents** را فعال کنید.
7. از مسیر **تنظیمات > Table of Contents** وارد صفحه تنظیمات شوید.

### نصب دستی

1. فایل افزونه را از حالت ZIP خارج کنید.
2. پوشه افزونه را در مسیر زیر قرار دهید:

`wp-content/plugins/table-of-contents/`

3. وارد پیشخوان وردپرس شوید.
4. به بخش **افزونه‌ها** بروید.
5. افزونه **Table of Contents** را فعال کنید.
6. سپس از بخش **تنظیمات > Table of Contents** تنظیمات فهرست مطالب را انجام دهید.

## 4. توضیحات کلی و ساده

پس از فعال‌سازی افزونه، تنظیمات فهرست مطالب از طریق صفحه تنظیمات در دسترس است.

### فهرست مطالب نوشته‌ها

در بخش **Articles** می‌توانید فهرست مطالب مخصوص نوشته‌های وبلاگ را فعال کرده و مواردی مانند سطح تیترها، عنوان، استایل، شماره‌گذاری، رنگ‌ها، اندازه متن، فاصله‌ها و رفتار Sticky را تنظیم کنید.

### فهرست مطالب محصولات

در بخش **Products** می‌توانید تنظیمات مستقل فهرست مطالب محصولات ووکامرس را انجام دهید.

محل قرارگیری فهرست مطالب محصول نیز می‌تواند متناسب با ساختار محصول تنظیم شود.

### استفاده از Shortcode

در صورتی که بخواهید فهرست مطالب را به صورت دستی در یک بخش مشخص قرار دهید، می‌توانید از Shortcodeهای اختصاصی استفاده کنید:

- `[hessamzm_blog_toc]`
- `[hessamzm_product_toc]`

در صفحه تنظیمات، برای این Shortcodeها سازنده اختصاصی وجود دارد و می‌توانید بدون حفظ کردن Attributeها، Shortcode مورد نظر را ایجاد و کپی کنید.

Shortcodeها امکان شخصی‌سازی مواردی مانند سطح تیترها، عنوان، استایل، شماره‌گذاری، Sticky، رنگ‌ها، تایپوگرافی، فاصله‌گذاری و متن باز و بسته کردن فهرست را فراهم می‌کنند.

### جلوگیری از نمایش دوباره فهرست مطالب

برای جلوگیری از ایجاد دو فهرست مطالب در یک محتوا، افزونه ارتباط بین TOC خودکار و Shortcode را مدیریت می‌کند.

اگر TOC خودکار یک نوع محتوا فعال باشد، Shortcode مربوط به همان نوع محتوا در سازنده Shortcode غیرفعال می‌شود تا کاربر به صورت اشتباهی یک TOC دوم ایجاد نکند.

### ویرایش و شخصی‌سازی

تمام تنظیمات اصلی از طریق رابط استاندارد پیشخوان وردپرس انجام می‌شوند و نیازی به ویرایش فایل‌های PHP یا CSS برای استفاده معمول از افزونه نیست.

افزونه با هدف استفاده ساده در سایت‌های معمولی و در عین حال امکان توسعه برای پروژه‌های حرفه‌ای طراحی شده است.

## پشتیبانی از ترجمه

رابط افزونه برای ترجمه آماده است و زبان‌های فارسی و انگلیسی را پشتیبانی می‌کند.

## سازگاری

افزونه از APIهای استاندارد WordPress استفاده می‌کند و برای استفاده در سایت‌های مدرن WordPress طراحی شده است.

در سایت‌های دارای WooCommerce، سازگاری با **High-Performance Order Storage (HPOS)** نیز در نظر گرفته شده است.
