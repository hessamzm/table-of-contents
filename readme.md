# Table of Contents

افزونه‌ای سبک و قابل توسعه برای ایجاد خودکار فهرست مطالب در WordPress.

## 1. معرفی افزونه

**Table of Contents** یک افزونه سبک و قابل توسعه برای ایجاد خودکار «فهرست مطالب» در WordPress است.

افزونه تیترهای موجود در محتوای نوشته‌ها و محصولات را شناسایی کرده و یک فهرست مطالب قابل تنظیم ایجاد می‌کند. ظاهر، ساختار و رفتار فهرست مطالب را می‌توان متناسب با نیاز سایت شخصی‌سازی کرد.

مهم‌ترین امکانات:

- ایجاد خودکار فهرست مطالب از تیترهای H1 تا H6
- تنظیمات مستقل فهرست مطالب برای نوشته‌های وبلاگ و محصولات WooCommerce
- پشتیبانی از نوشته‌ها، برگه‌ها و محصولات WooCommerce
- انتخاب سطح تیترهای مورد استفاده در فهرست مطالب
- شخصی‌سازی عنوان، استایل، شماره‌گذاری و نحوه نمایش
- پشتیبانی از Sticky و Scroll Spy
- طراحی Responsive برای موبایل، تبلت و دسکتاپ
- پشتیبانی از Gutenberg Block
- پشتیبانی از Shortcode برای درج دستی فهرست مطالب
- سازگاری با Rank Math و جلوگیری از ایجاد TOC تکراری در سناریوهای پشتیبانی‌شده
- حفظ IDهای موجود تیترها و مدیریت Anchorهای تکراری
- پشتیبانی از ترجمه و رابط کاربری فارسی و انگلیسی
- سازگاری با HPOS در WooCommerce

## 2. پیش‌نیازها

برای استفاده از نسخه 1.0.0 موارد زیر مورد نیاز است:

- **WordPress:** نسخه 7.0 یا بالاتر
- **PHP:** نسخه 8.2 یا بالاتر
- **WooCommerce:** نسخه 10.0 یا بالاتر، فقط برای امکانات مربوط به محصولات WooCommerce

برای استفاده از امکانات محصولات، WooCommerce باید نصب، فعال و با نسخه مورد نیاز سازگار باشد.

## 3. آموزش نصب

### نصب از طریق پیشخوان WordPress

1. فایل ZIP افزونه را دریافت کنید.
2. وارد پیشخوان WordPress شوید.
3. به مسیر **افزونه‌ها > افزودن افزونه** بروید.
4. گزینه **بارگذاری افزونه** را انتخاب کنید.
5. فایل ZIP را انتخاب و نصب کنید.
6. پس از نصب، افزونه **Table of Contents** را فعال کنید.
7. برای ورود به تنظیمات، به مسیر **تنظیمات > Table of Contents** بروید.

### نصب دستی

1. فایل ZIP افزونه را از حالت فشرده خارج کنید.
2. پوشه افزونه را در مسیر زیر قرار دهید:

`wp-content/plugins/table-of-contents/`

3. وارد پیشخوان WordPress شوید.
4. به بخش **افزونه‌ها** بروید.
5. افزونه **Table of Contents** را فعال کنید.
6. سپس از مسیر **تنظیمات > Table of Contents** فهرست مطالب را تنظیم کنید.

## 4. توضیحات کلی و ساده

پس از فعال‌سازی افزونه، تنظیمات فهرست مطالب از طریق صفحه تنظیمات در دسترس است.

### فهرست مطالب نوشته‌ها

در بخش **Articles** می‌توانید فهرست مطالب مخصوص نوشته‌های وبلاگ را فعال کرده و سطح تیترها، عنوان، استایل، شماره‌گذاری، رنگ‌ها، اندازه متن، فاصله‌ها و رفتار Sticky را تنظیم کنید.

### فهرست مطالب محصولات

در بخش **Products** می‌توانید تنظیمات مستقل فهرست مطالب محصولات WooCommerce را انجام دهید.

محل قرارگیری فهرست مطالب محصول نیز می‌تواند متناسب با ساختار صفحه محصول تنظیم شود.

### استفاده از Shortcode

اگر می‌خواهید فهرست مطالب را به صورت دستی در محل مشخصی قرار دهید، می‌توانید از Shortcodeهای اختصاصی استفاده کنید:

- `[hessamzm_blog_toc]`
- `[hessamzm_product_toc]`

در صفحه تنظیمات، برای این Shortcodeها سازنده اختصاصی وجود دارد و می‌توانید بدون حفظ کردن Attributeها، Shortcode را ایجاد و کپی کنید.

Shortcodeها امکان شخصی‌سازی سطح تیترها، عنوان، استایل، شماره‌گذاری، Sticky، رنگ‌ها، تایپوگرافی، فاصله‌گذاری و متن باز و بسته کردن فهرست مطالب را فراهم می‌کنند.

### جلوگیری از نمایش دوباره فهرست مطالب

برای جلوگیری از ایجاد دو فهرست مطالب در یک محتوا، افزونه رابطه بین TOC خودکار و Shortcode را مدیریت می‌کند.

اگر TOC خودکار یک نوع محتوا فعال باشد، سازنده Shortcode مربوط به همان نوع محتوا غیرفعال می‌شود تا کاربر به صورت اشتباهی TOC دوم ایجاد نکند.

### ویرایش و شخصی‌سازی

تمام تنظیمات اصلی از طریق رابط استاندارد پیشخوان WordPress انجام می‌شوند و برای استفاده معمول نیازی به ویرایش فایل‌های PHP یا CSS نیست.

افزونه برای استفاده ساده در سایت‌های معمولی و در عین حال توسعه‌پذیری در پروژه‌های حرفه‌ای طراحی شده است.

## پشتیبانی از ترجمه

رابط افزونه برای ترجمه آماده است و از زبان‌های فارسی و انگلیسی پشتیبانی می‌کند.

## سازگاری

افزونه از APIهای استاندارد WordPress استفاده می‌کند و برای استفاده در سایت‌های مدرن WordPress طراحی شده است.

در سایت‌های دارای WooCommerce، سازگاری با **High-Performance Order Storage (HPOS)** نیز در نظر گرفته شده است.
